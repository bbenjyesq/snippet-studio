# Changelog

## 1.0.0 — 2026-11-15

First public release.

- Gallery, Counsel and Docket views (⌘1–⌘3), with search.
- Create, edit, duplicate and delete snippets without touching YAML.
- Fill-in questions (short answer, long answer, pick-list), date, clipboard and cursor-position buttons, and a live "Try it" preview.
- Color groups and SF Symbol icons, kept in Snippet Studio's own file.
- Line-precise saving that preserves comments, with verification before every write, a backup before every change, and one-click restore.
- Read-only handling of command snippets, pattern-triggered snippets and installed packages.
- Crash-proof reading of match files.
- Keyboard shortcuts, VoiceOver labels and Reduce Motion support.
- Demo mode (`SNIPPET_STUDIO_DEMO`) with a sample library.
